# Starglider 2: original source restoration

Status: normal-media loader entries/bytes verified. Published source batches cover
startup, drawing masks, Paula sample assets, span dispatches, model/variant data,
secondary object updates, names, shared audio/render storage, frame/view and flight
state, projected discs, HUD sprites, text/input, contact lists and polygon
edge lookup/scratch contracts. Complete C/vasm
byte equality is preserved; 53432 bytes remain unclassified and substantial
function/field meaning remains unresolved. Panel-animation images export as
identified assets and projection scales are documented. The startup-transformed
novella-check region now has a separate reversible,
canonical readable view; its execution remains conditional and unobserved in the
bounded Amiga boot. Cockpit and Argonaut splash RLE streams now export as identified assets.
The world-object pool, update dispatch and selected motion fields now have
canonical names/types. Other game-record/function contracts remain open.
No interim archives.
Scope: the UA/WOW Amiga disk already imported in this repository. Restore readable
original absolute-address assembly, extracted assets and exact raw payloads. No
relocation, C conversion or replacement OS loader is part of this project.

## Model catalogue and encoded vertices

The constructor at runtime `$4A2A` selects from 104 LONG pointers at `$18974`.
Entries 0 and 1 intentionally point to the same header: there are 103 distinct
headers at `$18B14..$19570`. Their shared 24-byte prefix contains a last vertex
index, face count, coordinate-pool WORD count, four pointers, and auxiliary face
count. Only a nonzero auxiliary count causes the constructor to consume the
additional LONG at +24. The original catalogue has 58 short and 45 extended
headers. Canonical structures preserve that distinction and the pointer alias;
the shared-prefix pointer type does not assert a uniform 28-byte pointee.

The four prefix pointers identify normal face commands, eight-byte vertex
reference records, a coordinate WORD pool, and an optional vertex-variant pointer
table. The routine at `$56BC` masks each vertex coordinate reference with `$7FFF`
and uses it as a byte offset into the coordinate pool; the sign bit selects a
negated transformed result. These encoded references are not literal XYZ values.
The vertex resolver at `$583C` reads three such references and a fourth WORD:
a negative fourth WORD uses the base record, while a nonnegative value may
select an alternate triple from the chosen variant data. The instance's variant
selector at +3 is not bounded by these consumers alone; variant-table lengths
and variant data extents remain unresolved.

For every original model, the coordinate pool ends at its vertex records.
All three coordinate references in every base vertex are even and in that pool.
Every normal/auxiliary face vertex reference is a multiple of eight within its
model's vertex records. Normal face commands encode their vertex count in bits
10..8; auxiliary commands use bits 11..8. Parsing the declared face counts ends
exactly at the next component. Other face flags/material meanings and the visual
identities of the models have not been inferred. Components of distinct original
models do not overlap. This is original-record validation, not a guarantee for
arbitrary replacement data or all runtime selectors.

## Conditional variant bounds from the original model viewer

The four-byte records at runtime `$ECA2..$EE42` provide two endpoint pairs per
model ID. A negative start byte disables its span. The viewer clears the instance
selector at `$F0A0`; stepping at `$EF4C/$EFAA` moves toward an endpoint or switches

indexes the header's variant pointer table as `(selector-1)*4`. The Walker header

range. Ignoring that alias would incorrectly bound this table at zero.

## Cockpit and splash streams

The original Amiga decoder consumes four column-major plane streams after a
32-byte palette/control header. Controls 1..127 repeat the following byte;
129..255 copy `(-control)&127` literal bytes; zero ends the current plane.
Control `$80` would enter a 65536-iteration DBF loop and is outside the admitted
bounded resources. This is not a standard PackBits declaration.

The cockpit stream is `$5343C..$56552` (12566 bytes); the Argonaut space-station
splash stream is `$56574..$59F29` (14773 bytes). Their private decoded previews
