# Classic Mac OS Reference Markdown

Committed page-cited Markdown versions of local Classic Mac OS reference books.

These files are source-prep artifacts for Classic Mac OS / m68k platform
knowledge work. They are used as cited references, not as runtime metadata or
parsed truth. Structured KB JSON and reviewed corrections remain the owners of
platform facts.

Each document has:

```text
<stem>.md
<stem>.source.json
```

The Markdown keeps page markers:

```md
<!-- source-page: 42 -->
## Page 42
```

Current documents:

```text
Inside_Macintosh_Volume_I_1985.md
Inside_Macintosh_Volume_II_1985.md
Inside_Macintosh_Volume_III_1985.md
Inside_Macintosh_Volume_IV_1986.md
MPW_and_Assembly_Language_Programming_for_the_Macintosh_1987.md
Programming_With_Macintosh_Programmers_Workshop_1987.md
```

See `docs/pdf-to-md.md` for the conversion and repair workflow.

`macos_include_audit.json` is a review aid generated by comparing code-like
tokens in these Markdown files with `ext/macos_includes/mpw_gm/index.json`.
Findings are capped per document and must be reviewed before applying edits.

`macos_include_amendments.json` records accepted whole-token fixes made from the
audit. The current auto-applied set is limited to single-suggestion include
matches that differ only by case or OCR-confusable characters.

`macos_text_audit.json` and `macos_text_amendments.json` cover non-symbol OCR
cleanup. The auto-applied set is limited to explicit substitutions such as
split booleans, parameter-block OCR, and AppleTalk OCR; ambiguous page-reference
and spacing findings stay review-only.
