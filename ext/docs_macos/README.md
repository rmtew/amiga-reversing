# Classic Mac OS Reference Markdown

Committed page-cited Markdown versions of local Classic Mac OS reference books.

These files are source-prep artifacts for Classic Mac OS / m68k platform
knowledge work. They are used as cited references, not as runtime metadata or
parsed truth. Structured KB JSON and reviewed corrections remain the owners of
platform facts.

Each document has:

```text
<stem>.md
<stem>.source.json
```

The Markdown keeps page markers:

```md
<!-- source-page: 42 -->
## Page 42
```
